# Kettu MessageLogger

**Geliştirici: bay4lly**

Silinen ve düzenlenen mesajları sohbet içinde daha anlaşılır biçimde takip etmek için hazırlanmıştır.

## Neler yapar?

- Silinen mesajı sohbetten hemen kaybetmez.
- Silinen mesajı **kırmızı yazı** veya **kırmızı arka plan** ile gösterebilir.
- Silinen mesaja uzun basarak vurguyu beyaza çevirebilir, sonra tekrar kırmızı yapabilirsin.
- Düzenlenen mesajın önceki halini güncel mesajın üstünde gri olarak gösterir.
- Önceki sürümün saatini edit geçmişinde gösterir.
- Birden fazla düzenlemeyi sırayla saklar.
- Toplu mesaj silme olaylarını da yakalamaya çalışır.
- FakeNitro ile birlikte kullanılacak şekilde uyumluluk düzenlemeleri içerir.

## Kurulum

Kettu > **Settings > Plugins > +** kısmına:

```text
https://KULLANICI.github.io/REPO/MessageLogger/
```

adresini ekle. Plugin'i açtıktan sonra Discord'u tamamen kapatıp yeniden açmak iyi fikir.

> Plugin kurulmadan önce silinmiş mesajları geri getiremez. Discord arayüzü sürüme göre değiştiği için bazı güncellemelerde kırmızı görünüm gibi görsel özellikler ayrıca uyarlama isteyebilir.
