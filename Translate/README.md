# Kettu Translate

**Geliştirici: bay4lly**

Discord mesajlarını uygulamadan çıkmadan çevirmek için hazırlanmış Kettu eklentisi.

## Neler yapar?

- Mesaja uzun basıp **Mesajı Çevir** diyebilirsin.
- Çeviriyi panoya kopyalayabilirsin.
- İstersen gelen mesajları otomatik çevirebilirsin.
- Hedef dili ayarlardan seçebilirsin.
- Kodları, linkleri, mentionları ve özel emojileri mümkün olduğunca bozmadan bırakır.
- Bot mesajlarını veya kendi mesajlarını otomatik çevirinin dışında bırakabilirsin.

## Kurulum

Kettu > **Settings > Plugins > +** yoluna gir ve şu biçimde plugin klasör adresini ekle:

```text
https://KULLANICI.github.io/REPO/Translate/
```

Kurulumdan sonra eklentiyi aç. Gerekirse Discord'u tamamen kapatıp yeniden aç.

## Kullanım

Bir mesaja uzun bas. Menüdeki çeviri seçeneğini kullan. Otomatik çeviri ve dil ayarları plugin ayar ekranındadır.

> Çeviri internet bağlantısı kullanır. Özel DNS veya filtreleme servisi çeviri bağlantısını engellerse özellik çalışmayabilir.
