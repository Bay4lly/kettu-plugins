# Kettu AccountSwitcher+

**Geliştirici: bay4lly**

Mobil Discord'da çıkış yapmadan kayıtlı hesaplar arasında daha hızlı geçiş yapmak için hazırlanmıştır.

## Neler yapar?

- Birden fazla hesabı ayrı kartlar halinde saklar.
- Kayıtlı hesaba tek dokunuşla geçiş yapar.
- Hesaplara kendi isimlerini verebilirsin.
- Kayıtları PIN ile kilitleyebilirsin.
- Otomatik kilitleme süresini ayarlayabilirsin.
- Oturum anahtarını ekranda veya panoda göstermez.

## Kurulum

Kettu > **Settings > Plugins > +** kısmına:

```text
https://KULLANICI.github.io/REPO/AccountSwitcherPlus/
```

adresini ekle. Sonra plugin ayarından PIN oluşturup mevcut hesabını ekleyebilirsin.

## Önemli

Hesap oturum bilgileri hassastır. Plugin'i yalnızca kendi GitHub Pages adresinden veya güvendiğin kaynaktan kur. PIN'ini unutursan şifreli kayıtların geri açılamayabilir.
